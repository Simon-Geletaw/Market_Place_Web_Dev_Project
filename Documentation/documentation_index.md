# Documentation Index

This folder contains the project documentation set for the secure local service marketplace.

## How To Use These Documents

1. Read the roadmap first to understand the implementation sequence.
2. Use the database architecture and schema documents for backend structure.
3. Use the relationship document to understand table connections and workflow state transitions.
4. Use the UI/UX specification to design the interface and build screens.
